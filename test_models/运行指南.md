# 模型测试运行指南

本目录验证股票收益分布、未来实现波动率和市场状态模型。模型必须在严格的时间序列切分下与简单基准比较，不能只报告训练集拟合结果。

## 计划测试

1. `01_baselines.py`：历史均值、历史波动率、EWMA 和简单线性模型。
2. `02_walk_forward_split.py`：验证扩展窗/滚动窗切分以及训练、验证、测试隔离。
3. `03_return_distribution.py`：验证分位数预测、上涨概率与尾部概率输出。
4. `04_volatility_forecast.py`：比较 EWMA、GARCH 与机器学习波动率预测。
5. `05_probability_calibration.py`：检验概率校准、覆盖率和可靠性。
6. `06_reproducibility.py`：验证随机种子、环境和模型产物可复现。

## 运行方式

```powershell
cd "D:\ConvexEdge\test_models"
python 01_baselines.py
python 02_walk_forward_split.py
python 03_return_distribution.py
python 04_volatility_forecast.py
python 05_probability_calibration.py
python 06_reproducibility.py
```

## 通过标准

- 仅允许 walk-forward 或其他严格按时间推进的样本外评估。
- 每个复杂模型必须与朴素基准比较。
- 收益分布报告 Quantile Loss/CRPS 或等价指标；概率输出报告 Brier Score 与校准结果。
- 波动率模型报告样本外误差及高波动区间表现。
- 模型结果必须可由固定配置和随机种子复现。
