# 风险与权限测试运行指南

本目录验证策略在正常和极端情况下的风险边界，并保证账户权限变化只会缩小允许动作集合，不会绕过安全控制。

## 计划测试

1. `01_position_limits.py`：单标的、行业、总杠杆和期权张数上限。
2. `02_greeks_aggregation.py`：股票与期权组合 Delta/Gamma/Theta/Vega 汇总。
3. `03_tail_metrics.py`：最大回撤、Expected Shortfall 和压力损失。
4. `04_scenario_shocks.py`：价格、隐含波动率、利率和相关性联合冲击。
5. `05_permission_matrix.py`：Level 1/2 对策略动作的白名单控制。
6. `06_assignment_and_cash.py`：行权/指派后的现金、持仓和购买力风险。
7. `07_kill_switch.py`：行情陈旧、连接异常、超限和人工停机逻辑。

## 运行方式

```powershell
cd "D:\ConvexEdge\test_risk"
python 01_position_limits.py
python 02_greeks_aggregation.py
python 03_tail_metrics.py
python 04_scenario_shocks.py
python 05_permission_matrix.py
python 06_assignment_and_cash.py
python 07_kill_switch.py
```

## 通过标准

- Level 1 仅允许持股覆盖的 Covered Call/Buy Write；不得产生裸卖或 Long Option 实盘指令。
- Level 2 未启用时，相关策略仍可回测，但执行适配器必须拒绝发送。
- 风险上限在订单生成前和发送前各检查一次。
- 极端场景覆盖股票跳空、IV 飙升、价差扩大、提前指派和数据中断。
- 任一关键行情陈旧或账户状态未知时，系统必须停止新增风险。
