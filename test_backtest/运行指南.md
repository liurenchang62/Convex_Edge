# 统一回测测试运行指南

本目录验证股票与期权共用的事件驱动回测器。Level 1 和 Level 2 策略必须使用同一成交、成本和资金账本，避免因回测口径不同产生虚假优势。

## 计划测试

1. `01_stock_ledger.py`：股票现金、持仓、分红、拆股和已/未实现盈亏。
2. `02_option_lifecycle.py`：期权开仓、估值、到期、行权、指派和合约乘数。
3. `03_transaction_costs.py`：佣金、Bid/Ask、滑点和不可成交规则。
4. `04_covered_call.py`：持股覆盖检查、权利金、封顶收益和被指派结果。
5. `05_level2_overlays.py`：Protective Put、Long Call/Put、Debit Spread、Straddle/Strangle。
6. `06_no_lookahead_execution.py`：确认信号时间、下单时间和成交价格顺序正确。
7. `07_regression_scenarios.py`：使用可手算的小型路径锁定回测结果。

## 运行方式

```powershell
cd "D:\ConvexEdge\test_backtest"
python 01_stock_ledger.py
python 02_option_lifecycle.py
python 03_transaction_costs.py
python 04_covered_call.py
python 05_level2_overlays.py
python 06_no_lookahead_execution.py
python 07_regression_scenarios.py
```

## 通过标准

- 组合资产恒等式在每个事件后成立。
- 期权每张默认乘数 100，但必须读取合约实际乘数。
- 成交价不得优于当时可见 Bid/Ask；无可交易报价时不得虚构成交。
- Covered Call 未持有足量股票时必须拒绝开仓。
- 到期、自动行权和提前指派均有确定性回归样例。
- 所有策略同时报告毛收益和扣除成本后的净收益。
