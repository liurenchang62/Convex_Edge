# ConvexEdge 数据接入测试指南

本目录只测试连接和数据拉取，**没有任何下单代码**。默认连接真实账户 TWS：`127.0.0.1:7496`。当前请保持 TWS 的“只读 API”开启。

## 准备

在 PowerShell 中：

```powershell
python -m pip install ibapi
cd "D:\ConvexEdge\test_data"
```

保持真实账户 TWS 已登录、API 已启用、端口为 `7496`。不同脚本使用不同 `client-id`，避免连接冲突。

## 逐项运行

| 文件 | 测试内容 | 命令 |
|---|---|---|
| `01_connection_account.py` | 连接、账户净值/现金/购买力（只读） | `python 01_connection_account.py` |
| `02_contract_details.py` | 股票、外汇、指数合约解析 | `python 02_contract_details.py` |
| `03_market_snapshot.py` | 股票、外汇、指数一次性报价 | `python 03_market_snapshot.py` |
| `04_streaming_quotes.py` | 股票实时流式报价与成交数据 | `python 04_streaming_quotes.py --symbol AAPL --seconds 10` |
| `05_historical_bars.py` | 股票历史 5 分钟 K 线 | `python 05_historical_bars.py --symbol AAPL --duration "2 D" --bar-size "5 mins"` |
| `06_option_chain.py` | 个股期权到期日、行权价、交易类别 | `python 06_option_chain.py --symbol AAPL` |
| `07_market_depth.py` | 股票 Level-2 市场深度 | `python 07_market_depth.py --symbol AAPL --seconds 10` |
| `08_option_quote_greeks.py` | 指定期权的报价、隐含波动率与 Greeks | 先运行 06 获取到期日/行权价，再运行 `python 08_option_quote_greeks.py --symbol AAPL --expiry 20261016 --strike 250 --right C` |
| `09_bond_contract_details.py` | 用 CUSIP/ISIN 解析债券并查看期限、票息等 | `python 09_bond_contract_details.py --id 你的CUSIP或ISIN` |
| `10_bond_market_snapshot.py` | 债券价格、规模及可用收益率快照 | `python 10_bond_market_snapshot.py --id 你的CUSIP或ISIN` |
| `11_bond_historical_bars.py` | 债券历史价格；公司债还可请求收益率 | `python 11_bond_historical_bars.py --id 你的CUSIP或ISIN --duration "1 M" --bar-size "1 day" --what-to-show BID_ASK` |

## 一键运行全部测试

默认债券为美国财政部 2036 年到期、CUSIP `91282CQQ7` 的 10 年期国债。期权合约不会设置会随时间失效的默认值；先运行 06，再把其返回的有效到期日和执行价传给一键测试：

```powershell
python run_all.py --option-expiry YYYYMMDD --option-strike 行权价 --option-right C
```

暂时没有期权参数时也可运行；只有期权 Greeks 测试会显示 `SKIP`：

```powershell
python run_all.py
```

出现 `PASS` 表示请求正常结束；没有数值但请求结束，通常是交易时段或行情订阅问题。08 中的示例到期日和行权价仅演示命令格式，必须替换为 06 实际返回的有效合约。错误 `10089/10167/354` 通常表示缺少相应实时行情权限；TWS 若允许延迟行情，部分请求会自动返回延迟数据。Level-2 需要单独的深度行情权限。

测试不会把“连接成功但收到 0 条行情”计为通过。当前机器的 PyPI `ibapi 9.81.1` 过旧；若出现错误 `10285`，需从 IBKR 官方 TWS API 下载页安装最新版 Python API（协议版本至少 163）。实时股票、OPRA 期权、CBOE 指数和完整 Level-2 数据还分别受账户行情订阅限制。

债券必须传入 TWS 中可搜索到的准确 CUSIP 或 ISIN。先运行 09，确认成功解析出 `conId` 后再运行 10 和 11。公司债收益率历史示例：

```powershell
python 11_bond_historical_bars.py --id 你的CUSIP --what-to-show YIELD_BID_ASK
```

可统一覆盖连接参数，例如：

```powershell
python 03_market_snapshot.py --host 127.0.0.1 --port 7496 --client-id 203
```

## 安全边界

- 这一阶段不要取消 TWS 的“只读 API”。
- 后续真实下单测试应单独建目录，并加入金额上限、白名单、二次确认和订单回读；不要把下单逻辑混入本目录。
- `7496` 通常是 TWS 实盘端口，`7497` 通常是 TWS 模拟盘端口；最终以你的 TWS 配置为准。
