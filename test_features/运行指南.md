# 特征与标签测试运行指南

本目录负责验证研究数据能否安全地转化为模型输入。这里最重要的目标不是“成功生成一张表”，而是证明特征在决策时点真实可见，没有未来数据泄漏。

## 计划测试

1. `01_point_in_time_alignment.py`：验证价格、财报、宏观和公司事件均按真实发布时间对齐。
2. `02_return_labels.py`：验证多周期前瞻收益标签、复权规则和交易日边界。
3. `03_realized_volatility.py`：验证 Close-to-Close、Parkinson 等实现波动率计算。
4. `04_option_surface.py`：验证期权链清洗、期限插值、Moneyness/Delta 对齐和无套利检查。
5. `05_feature_missingness.py`：统计缺失、异常值、陈旧报价和不可交易样本。
6. `06_no_leakage.py`：通过刻意注入未来字段，确认管线能够阻止泄漏。

## 运行方式

对应实现加入本目录后，逐项运行：

```powershell
cd "D:\ConvexEdge\test_features"
python 01_point_in_time_alignment.py
python 02_return_labels.py
python 03_realized_volatility.py
python 04_option_surface.py
python 05_feature_missingness.py
python 06_no_leakage.py
```

全部脚本就绪后再增加 `run_all.py`，统一按编号运行。禁止用无断言的占位脚本冒充通过。

## 通过标准

- 每个样本记录 `as_of_time`、数据来源时间和可交易时间。
- 标签区间与特征区间不重叠。
- 股票复权、期权乘数、分红和拆股处理可被小样本手工复算。
- 期权报价必须过滤交叉价、零报价、过宽价差和陈旧数据。
- 任意未来字段进入特征集合时，测试必须失败。
