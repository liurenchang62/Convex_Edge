# ConvexEdge 当前架构

## 1. 接入与安全边界

`test_data` 和 `scripts/collect_ibkr_*` 只调用 IBKR 查询接口。数据采集与订单测试分离；订单脚本仍默认 WHAT-IF。Level 2 未开放时，Level 2 策略只能进入研究和回测动作空间。

## 2. 原始数据层

IBKR 股票日线、日内 K 线和期权链引用数据首先进入 `data/raw`。每个快照由 `data.parquet` 和 `manifest.json` 组成，记录请求参数、抓取时间、模式、行数和 SHA-256。快照不可覆盖，且默认不提交 Git。

## 3. Point-in-Time 层

日内观测使用 `event_time`、`source_time`、`available_time` 和 `as_of_time`。任何在决策时尚不可见的数据会使管线失败。日线只保留供应商真实提供的 `session_date`，并标记为下一实际观测交易日可用，不虚构具体收盘时间。

## 4. 特征与标签层

当前包含日收益、Close-to-Close 波动率、Parkinson 波动率，以及 1/5/21 日前瞻收益和未来实现波动率标签。预测字段选择器显式排除所有 `forward_*` 与 `label_*` 字段。

## 5. 模型层

模型层输出收益分位数、上涨概率和未来实现波动率。训练采用按完整交易日推进的 walk-forward；训练、验证与测试之间设置等于预测期限的 gap。复杂模型始终和历史分布、EWMA、GARCH 与线性模型在相同测试折上比较。

## 6. 研究产物

每次实验保存所有样本外预测、输入快照哈希、特征名称、随机种子、切分参数和评价指标。模型选择不能只看汇总 Sharpe，也必须检查概率校准、区间覆盖率、高波动状态和稳定性。

## 7. 尚未实现的后续层

下一阶段是统一事件驱动回测器：股票与期权共享现金和持仓账本，并处理成本、分红、拆股、到期、行权和指派。之后才把预测分布映射为股票、现金和权限允许的期权动作。
