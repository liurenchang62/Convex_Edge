# AAPL 五年模型基线结果

本报告是管线验证，不是可交易 Alpha 结论。

## 设置

- 数据：IBKR AAPL `ADJUSTED_LAST` 日线。
- 区间：2021-10-04 至 2026-10-02，共 1,255 个交易日。
- 目标：未来 5 个交易日收益分布、上涨概率和实现波动率。
- 切分：最少 252 日训练、63 日验证、63 日测试、分区间隔 5 日。
- 样本外预测：882 条。
- 随机种子：42。

## 观察

- 历史分布的 10%/50%/90% Pinball Loss 分别为 0.007180、0.014414、0.006462。
- 条件分位数模型分别为 0.008365、0.018740、0.008671，未击败历史分布。
- 历史中位数收益 MAE 为 0.028828；条件中位数为 0.037481；线性模型为 0.039404。
- 历史上涨概率 Brier Score 为 0.248943；校准后的条件模型为 0.283453，表现更差。
- 历史区间覆盖率为 83.90%；条件模型只有 58.73%，存在明显覆盖不足。
- 波动率 RMSE：线性 0.132433、EWMA 0.143434、ML 0.150794、GARCH 0.165961。
- 高波动样本 MAE：GARCH 0.173616 最低，EWMA 0.184953、线性 0.195552、ML 0.198765。

## 解释

当前特征主要来自单一标的价格和区间波动率，信息量有限。结果说明不能假设复杂模型自然优于简单基准。下一轮研究需要扩大到严格 point-in-time 的多股票面板，并加入横截面、市场状态、成交量、基本面和事件特征；只有在独立样本外持续改善后，预测才能进入组合决策。
