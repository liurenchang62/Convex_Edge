# ConvexEdge 订单执行测试指南

本目录连接 TWS 实盘端口 `7496`，覆盖股票、美国个股期权和美国国债。默认仅运行 `whatIf` 预检，不会形成真实订单。

## 最小数量与风险

- 股票：TWS API 不支持按现金金额买股票，测试最小为 **1 股**。
- 期权：最小为 **1 张**，通常对应 100 股；默认限价 `$0.01`，权利金约 `$1`，另有佣金。
- 美国国债：通常最小为 **1,000 美元面值**，且具体债券可能要求更高。账户必须有足够购买力。
- 实盘测试均为限价买单，未成交时默认 10 秒后撤单；极端行情下仍可能立即成交，自动撤单不能消除风险。

## 先运行安全预检

```powershell
cd "D:\ConvexEdge\test_order"
python run_all.py
```

## 实盘发送

确认 TWS 当前登录目标真实账户，并取消“只读 API”后：

```powershell
python run_all.py --confirm-live I_UNDERSTAND_LIVE_ORDER
```

建议逐项执行：

```powershell
python 01_stock_order.py --confirm-live I_UNDERSTAND_LIVE_ORDER
python 02_option_order.py --expiry 20261016 --strike 400 --right C --confirm-live I_UNDERSTAND_LIVE_ORDER
python 03_bond_order.py --confirm-live I_UNDERSTAND_LIVE_ORDER
```

期权参数到期后，先用数据测试目录查询有效合约：

```powershell
python "D:\ConvexEdge\test_data\06_option_chain.py" --symbol AAPL
```

默认标的：Ford (`F`) 1 股限价 `$1.00`；AAPL 期权 1 张限价 `$0.01`；美国国债 `91282CQQ7` 1,000 美元面值限价 `90.00`。低限价用于验证订单接收、状态回报与撤单，不保证成交。
